    Shipped, open source

    An adversarial plan-review harness. One model drafts an implementation plan, a second attacks it in a read-only sandbox and returns a verdict, and the loop repeats until the plan survives or hits a round cap. Read-only is enforced by mechanism, not by asking politely.

  4. 04

    ccspike

    Shipped, open source

    Ranks the requests that dominated a Claude Code usage window, per token category and per tab, reading transcripts already on disk. On one measured five hour window of 425 requests, ten requests held 79.4% of cache creation. Widen the same workload to 24 hours and that flattens to 34.3%, so every ranking prints its own share and you can see whether it means anything before acting on it. It never sums token categories and never claims causation, because neither is identifiable from the data.

    TypeScriptNodeCLIzero runtime depsMIT
    Shipped github.com/Joshua-Anojulu/ccspike

  2. 06

    Domain shift in remote sensing

    Research

    A ResNet50 fine-tuned on EuroSAT reaches 98% benchmark accuracy, then collapses out of biome: F1 of 0.001 in the Congo Basin, on a composite the diagnostics show to be clean. A label-free AdaBN pass recovers it to 0.397. Benchmark accuracy does not transfer for free.

    PyTorchResNet50EuroSATSentinel-2AdaBN
    Result held Source restricted
  3. 07

    Anti-virulence screen

    Research, null result

    A structure-based docking screen against a bacterial virulence target. The result is null, and the SpeB positive control failed. A screen that cannot recover its own positive control cannot rank actives, so the work is being reframed as a benchmark of the pipeline itself.

    dockingAutoDockRDKitcontrols
    Null Source restricted
